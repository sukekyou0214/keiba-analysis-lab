# 参考順位の回顧検証（2026-11-04）

現行の参考順位を予想の主軸として採用できる根拠は確認できていない。初期画面は「今回条件・前走」とし、参考順位は研究中の機能として本体内に残す。今回の結果を見て重みを調整することはしない。

## 対象と方法

- エリザベス女王杯2016〜2025年の10レース、169出走記録。取得済み馬別戦績2,666走を使用。
- 京都は7開催116出走、阪神は2020〜2022年の3開催53出走。各年の実際の開催条件で再計算し、集計を分ける。
- 各開催日より前のG1〜G3のみを使用。対象レースIDは除外し、対象結果と馬別戦績の日付不一致は停止する。
- 対象レースの結果・確定人気・実際のペースは予測に渡さない。確定人気は予測後の比較基準にだけ使用する。
- 想定S/M/Hをそれぞれ固定。結果から良かったシナリオを選ばない。
- 同順位は全馬を含める。結果表の順番で同点を分けない。率の分母は結果確認済みの選出馬。
- 参考点は頭数補正着順40%、同場同距離20%、同距離15%、同場10%、想定ペース別15%。欠損を除いて重みを再配分。有効成績3走以上・項目充足率60%以上で提示。
- 「共通対象」は参考点で順位を提示できた馬に対象を揃えた比較。全体の比較とは区別する。

## 判断と限界

京都の順位提示率は27.6%、阪神は35.8%。欠損による保留が多く、全出走馬を比較できていない。同じ対象馬に揃えた着順のみの比較に対して、追加項目の有効性は確認できていない。

確定人気との比較は全体と共通対象で母集団が異なる。京都7レース、阪神3レースの少数例で、同じ馬が複数年に出走することもある。数ポイントの率差を優位性・勝率・期待値へ換算しない。

レース格内の難易度、相手関係、走破時計、馬場差は未補正。過去S/M/Hも不足している。取得済みの履歴だけに基づく回顧検証であり、独立した将来期間の検証ではない。

次の改善では、欠損と順位保留の原因、レース格・相手関係の扱いを先に整理する。追加した条件を同じ10レースだけで最適化せず、将来データでの検証計画と分けて管理する。
