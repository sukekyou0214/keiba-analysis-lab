# 手順：当日の情報（馬体重・その日の馬場の偏り）を使う予想の保存

v8b（`docs/accuracy/00` の 2026-11-26 追記「v8」）が影の予測に加わった場合だけ使う。それまでは、いつもの週末の手順（金曜〜前日の保存）のまま。

## 時刻
- JRA は、各レースの発走の約60〜70分前に馬体重を発表する。
- v8b の予想は、そのレースの馬体重の発表後・発走前に作って保存する。保存した時刻より前に発走したレースは、前向き評価に数えない。
- その日の馬場の偏りは、そのレースより前に終わった同じ競馬場の芝のレースの結果から作る。結果の取得が間に合わないレースは、偏りを0として計算し、そのことを記録に書く。

## 手順（当日）
1. 前日までの予想（全馬共通・v3・v5 など）は、いつもどおり前日までに `records/predictions/` に保存しておく（これは変えない）。
2. 当日、レースごとに（または数レースまとめて）次をする。取得は本番アプリの共通ゲートだけを通す。拒否されたら待ち、2回続けて拒否されたら止めて報告する。
   - 出馬表（馬体重入り）を取り直す。
   - そのレースより前に終わった同じ競馬場の芝のレースの結果を取る。
   - v8b を計算し、`records/predictions/<日付>_v8b/` に保存する（保存時刻・馬体重の発表を確かめたこと・使った前のレースの一覧を run_log に書く）。
   - 保存時刻が発走より前であることを確かめてから、コミットする。
3. 結果の照合は、いつもの週末の照合と一緒に行う。v8b は、保存時刻が発走前のレースだけを数える。

## 注意
- 馬体重の発表から発走までは1時間ほどしかない。取得や計算が遅れたレースは、保存しない（数えない）。遅れたことは記録に書く。
- 当日の情報を使っても、点数は確率ではない。オッズは使わない（M1 で確かめる「確定オッズ」は発走直前の値で、保存の時点では分からない）。
