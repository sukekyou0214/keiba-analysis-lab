# 指示書：地方（浦和）の全レース予想・信頼度別・結果照合

このまま Claude（Claude Code・このリポジトリ）に送れば、同じ作業を最初からやり直せるように書いてあります。
日付と競馬場は、使うたびに書き換えてください。

---

## プロンプト（ここから下を送る）

競馬分析ラボ（リポジトリ sukekyou0214/keiba-analysis-lab、作業ブランチ claude/keiba-lab-handover-5g9drw）で、
**2026-11-25（水）浦和の全レース**の地方ベースの参考順位と、信頼度別を出してください。レースが終わったら、結果の照合もしてください。

### 守ること
- 予想はラボの計算だけで出す。AIが馬を選んだり、順位を手で直したりしない。
- 取得は本番アプリの共通ゲート（keiba_fetch_policy）だけを通す。直接の取得や、制限を回避することはしない。拒否されたら待つ。
- 生データや秘密情報は GitHub に置かない。置いてよいのは、レース前の順位の記録・検証ログ・照合結果だけ。
- 点数は確率として出さない（0〜100 はレース内の相対点）。「おすすめ」は根拠なしに書かない。
- 新しいモデルや区分は、計算する前に docs/accuracy/00-plan-and-preregistration.md へ判定の規則を書いてから使う。
- /tmp や Streamlit のメモリを、保存先として扱わない。レース前の記録は records/predictions/ に入れてコミットする。

### 手順
1. **取得（本番）**
   `NAR_DATE=20261125 NAR_KEY='場:浦和' node scripts/ops/nar_prod.js start`
   - 状況は `... status` で確認する。「状態：完了」になったら、次のコマンドで ZIP を取り、空のフォルダに展開する。
     `... zip <空のフォルダ>`
   - 当日に実行すると、まだ発走していないレースだけが対象になる。前日に実行すると全レースが対象になる。
2. **学習データを増やす**
   前日以前に取った浦和のフォルダ（例：11/24 分）も、`--nar-work` に一緒に渡す。最初に書いたフォルダが予想の対象になる。
3. **計算**
   `python -I scripts/nar_local.py --nar-work <11/25のフォルダ> <11/24のフォルダ> --out <出力> --date 2026-11-25 --version auto`
   - v1 と v2（v1＋内枠点＋騎手の地方3着内率）を、同じ検証の走（8/1〜11/23）の AUC で比べる。
     v2−v1 の95%区間の下限が0を上回ったときだけ v2 を使う（00 の 2026-11-25 追記のとおり）。
   - 使う方式が「近走人気だけ」を上回るかも確かめる。上回らなければ「根拠不足」と書く。
   - 出力：`地方参考順位_<日付>.csv`（各レースの順位・地方点）、`信頼度区分_<日付>.csv`（A/B/C）、`run_log.json`（検証結果）。
4. **信頼度別**
   ボックス向きの順（頭数の少ない順、同じなら上位5頭と6位以下の点差の大きい順）で、上位3レースを A、4〜6 を B、7 以下を C とする。
   地方の戦績が2走未満の馬が2頭以上いるレースは、1段下げる。
   「JRA芝で確かめた選び方を当てはめたもので、地方の的中率は未確認」と必ず書く。
5. **送る**
   HTML（スマホで見やすい形。信頼度 A→B→C の順に、各レースの上位5頭の馬番・馬名・騎手・地方点）と CSV を作って送る。
   検証の数字（AUC と、近走人気だけとの差）と注意点を添える。
   レース前に `records/predictions/<日付>_urawa_local/` へ保存してコミット・プッシュする（PR → CI 通過 → スカッシュマージ → `git merge -s ours origin/main`）。
6. **レース後の照合**
   `NAR_DATE=20261125 NAR_KEY='結果' node scripts/ops/nar_prod.js start` → 完了したら zip を取り、照合する。
   - 照合は、レース前に保存した予想だけを使う。保存した時刻より前に発走したレースは対象外。
   - 出す数字：上位3頭に勝ち馬、予想1位の勝ちと3着以内、上位5頭ボックスの的中、実際の払戻での三連複（10点）と三連単（60点）の回収率、信頼度別の的中、参考として当日の人気上位5頭のボックス。
   - 結果は `records/predictions/<日付>_urawa_local/` に追記してコミットする。

### 報告のしかた
- 先に結論を書く（何レース分を出したか、どの方式を使ったか、検証で通ったか）。
- 表は「信頼度・レース・発走・頭数・上位5頭」。
- 限界を必ず書く：学習は出走馬自身の戦績だけで、レース単位の的中率は未確認。馬場・オッズ・馬体重・取消は入っていない。
