- 2026-03-28〜05-31 の JRA 芝・平地 311R、全出走馬 2,948 頭と戦績。本番の共通ゲート経由で取得（拒否による停止なし）。

- v1・v2（戦績の基準モデル、全馬共通との順位平均）と v4（騎手点を追加）は、4つの期間を通して全馬共通方式と主指標で確認できる差がない。
