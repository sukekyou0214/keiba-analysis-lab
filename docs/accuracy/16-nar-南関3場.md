## 判定と反映
- 大井：C2U − 近走人気だけ の下限 +1.1pt ＞ 0 → 採用。〜11/24 の大井で学習し直して `models/nar_大井.json`（採用）に保存。nar_local は大井でこれを主予測に使う。
- 川崎・船橋：下限が0以下 → nar-local-v1 のまま「根拠不足」。
- 信頼度：大井・川崎は未確認。船橋は、今の区分では下限 −4.2pt で届かず、事前に決めていた予備の区分（頭数だけ、選択の期間で選んだもの）で下限 +0.2pt となり「確かめ済み」。
  ただし (1) 下限がほぼ0で、2つ目の区分で通ったものである、(2) 確かめたのは C1S の順位の5頭ボックスで、船橋の今の主予測（nar-local-v1）の順位ではない。
  `models/nar_tiers.json` にこの2点を注記として残し、nar_local は船橋で「頭数だけ」の区分を使う。
- 3場とも、これからの開催日のレース前の記録が100レースたまったら、事前登録の規則で1回だけ見直す。
