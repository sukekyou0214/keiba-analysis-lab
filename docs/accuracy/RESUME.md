## 次にやること
1. 本番で収集が「完了」になったら、管理・検証の同セクションで「ZIPを作成」→ダウンロード（自動操作なら `node bt.js zip <保存先>`）。
2. ZIPを空のフォルダへ展開し、実験を実行：
   `python scripts/accuracy_experiment.py --backtest <展開先> --out <出力先>`
3. 出力（summary.csv、layers.csv、run_log.json、inner_*.csv、pace_summary.csv）を `02-results-*.md` にまとめ、
   事前登録の採用条件で判定する。outer の結果を見て設定を変えない。
4. 採用条件を満たさない場合：`models/v1.json` を影の予測として追加（主予測は変えない）。満たす場合も、主予測の切替は別PRで行い、旧方式・全馬共通は残す。
5. 展開予測：inner で選んだしきい値を `models/pace_v1.json` に保存。outer で「最多判定」を上回らなければ「暫定」のまま。
6. `docs/accuracy/status.json` を検証結果で更新（画面の検証状況に出る）。
