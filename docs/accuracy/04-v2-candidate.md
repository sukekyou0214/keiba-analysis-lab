# v2 候補の選択（開発用データ）と影の予測への追加

作成：2026-11-16。手順は `00-plan-and-preregistration.md` の 2026-11-16 追記「v2 候補の作り方」（候補を計算する前に固定）のとおり。

## 方法
- 2025年秋 377R で学習し、2026年秋 280R で主指標（上位3勝ち馬捕捉、新馬戦などの保留は失敗）を比べた。
- どちらの期間も結果を見た開発用データなので、ここでの差は改善の証拠ではない。判断は 11/21 以降の事前保存の予想で行う。
- 再現：`python scripts/v2_candidates.py --train-backtest <2025> --valid-backtest <2026> --out <出力> --save models/v2.json`

## 結果（2026年秋 280R）

| 候補 | 内容 | 上位3に勝ち馬 | 上位5 | 首位の勝率 |
|---|---|---|---|---|
| C1 | v1 の仕様のまま係数を学習し直し | 124（44.3%） | 59.3% | 26.1% |
| **C2** | **全馬共通（ペース項目なし）と v1 の順位の平均** | **126（45.0%）** | 60.0% | 26.1% |
| C3 | v1 ＋ 全馬共通の点数 | 125（44.6%） | 59.6% | 24.8% |
| C4 | 特徴量の選び直し（着差が外れた） | 124（44.3%） | 58.9% | 26.6% |
| 参考 | 全馬共通（ペース項目なし） | 119（42.5%） | 59.6% | 19.7% |
| 参考 | 旧方式 | 52（18.6%） | 26.1% | 12.5% |

- 差の区間（2,000回）：C2 − C1 ＝ +0.7pt（−1.8〜+3.2）、C2 − 全馬共通 ＝ +2.5pt（−0.7〜+5.7）。どれも差を確認できる大きさではない。
- 事前に決めた規則（C1 を上回る最上位、同率なら番号の小さい方）で **C2 を v2 とした**。

## v2 の扱い
- `models/v2.json`（版 v2-f8db5b0de2）：2025年秋＋2026年秋の全レースで学習し直した v1 部分の係数と、「順位平均」の指定。
- 週末一括分析で、v1 と並べて結果前に保存する（影の予測。主画面は現行の全馬共通のまま）。
- 全馬共通部分は、過去検証と同じ「想定ペース項目なし」で計算する（主画面の全馬共通とは別に計算）。
- 11/14・15 の取得データで取得なしの再実行を行い、38R すべてで v2 の記録が保存され、32R（新馬戦以外）で v1 と順位が違う（平均が効いている）ことを確認した。
- 前向きの判断は 2026-11-16 追記（final）の規則：事前保存 100R 以上で1回だけ、全馬共通と比べる。
