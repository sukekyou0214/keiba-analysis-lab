# 15. nar-v1S（南関東4場版）の前向きの確かめ（浦和）

事前登録：`docs/accuracy/00-plan-and-preregistration.md` の 2026-11-25 追記「第2段階 A」。

## モデル
- `models/nar_v1s.json`：レース単位の条件付きロジット。特徴量の組は第1段階で選んだ C3（基本＋地方の4つ＋格付けの3つ）に固定し、選び直していない。
- 学習：南関東4場（浦和・大井・川崎・船橋）の 2026-11-24 までの全レース、1,777レース。2026-11-25 に学習（学習だけ。この時点では成績を見ていない）。
- 主予測ではない。浦和の予想ページと記録に「参考：南関東4場版（検証中）」として、`nar-v1S順位`・`nar-v1S点` の列で並べる。

## 確かめ方（事前登録のまま）
- 2026-11-26 以降の浦和の開催日で、レース前に `records/predictions/<日付>_浦和_local/` に保存したレースだけを使う。9/1〜11/24 の浦和は第1段階で見たので使わない。
- 比べる相手：その時点の浦和の主予測（今は nar-local-v1）、近走人気だけ、nar-local-v1、参考として当日の人気。
- 100レースたまったら1回だけ判定する：nar-v1S − 浦和の主予測（上位3に勝ち馬）の95%区間（2,000回、種0）の下限＞0 なら、浦和の主予測を nar-v1S に替える。
- それまでは、累計のレース数と途中の成績を記録するだけで、判定はしない。
