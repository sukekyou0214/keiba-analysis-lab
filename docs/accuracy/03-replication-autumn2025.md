- 期間：2025-train 143R（09-13〜10-13）、2025-eval 234R（10-18〜11-30、うち新馬戦 42R）。
- 再現：`python scripts/replicate_v1.py --backtest <2025のZIP展開先> --out <出力先> --previous <2026年の実験出力>`。
  同じスクリプトを 2026 年のデータ・2026 年の期間で動かすと、02 の結果（v1 44・全馬共通 42・旧方式 22／101R、区間も同じ）を再現する。

## 層別（合わせた 335R、10R以上の層、v1 − 全馬共通）
- 良くなった層：OP +10.5pt（19R）、2勝 +8.9pt（45R）、〜1400m +7.6pt（92R）、2300m〜 +5.6pt（18R）
- 悪くなった層：3勝 −4.3pt（23R）、1900〜2200m −3.6pt（83R）、1500〜1800m −2.8pt（142R）、新潟 −1.9pt
- 変わらない層：1勝・未勝利（±1pt程度）、京都・福島（±0）、東京 +1.6pt
- 10pt 以上悪化した層はない。

## 採用判断：基準v1 は **主予測に採用しない（影の予測を継続）**
1. 2025-eval で旧方式・全馬共通の両方を上回る → **満たさない**（41.9% ＜ 42.3%）
2. 合わせた差の95%区間の下限が0以上 → **満たさない**（−4.2pt）
3. 順位付与率が5pt以上下がらない → 満たす（+1.8pt／+1.9pt）
4. 10pt 以上悪化する層がない → 満たす
5. 評価期間が60R以上 → 満たす（234R）

2つの期間・合わせて 335R で見て、v1 は主指標で全馬共通方式と差がない（±5pt 程度の幅に収まる）。
「v1 は全馬共通より上位3の捕捉が良い」とは言えない。主画面は現行（全馬共通方式）のまま。

## 分かったこと
- 全馬共通方式は、2つの期間で続けて旧方式を大きく上回った（2025：42.3% 対 17.1%、2026：41.6% 対 21.8%）。
  無作為（約24〜26%）も上回る。ただし旧方式との差の多くは、旧方式が順位を付ける馬が少ないこと（約36%）から来ている。
- v1 は首位の勝率・上位5の捕捉・順位相関で良い傾向があるが、判断の指標ではないので、これだけを理由に採用しない。
  見るなら、首位の勝率などを主指標にした新しい事前登録と、未使用の期間（11/21 以降の事前保存）が必要。
