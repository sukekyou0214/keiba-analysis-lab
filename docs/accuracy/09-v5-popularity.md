# v5（近走人気を追加）の検証と影の予測への追加

作成：2026-11-17。手順は `00-plan-and-preregistration.md` の 2026-11-17 追記「v5」（計算前に固定）のとおり。

## 方法
- v5 ＝ v3 の新馬戦以外のロジットに「近走人気」（直近5走の人気を頭数で補正した平均。過去のレースの人気で、予想時点で分かっている）を1つだけ追加。新馬戦は v3 と同じ騎手点。当日のオッズ・人気は使わない。
- v3・v5 とも 2025年秋だけで学習し、2026年夏 552R＋2026年春 311R で比較（他の比較には使ったが、この特徴量の結果は見ていない期間）。
- 再現：`python scripts/v5_test.py --train-backtest <2025年秋> --test-backtest <2026年夏> <2026年春> --out <出力>`

## 結果（合計 863R）

| 方式 | 上位3に勝ち馬 | 首位の勝率 | 首位の3着内率 |
|---|---|---|---|
| 全馬共通（主画面・ペース項目なし） | 415（48.1%） | 24.0% | 55.6% |
| v3 | 466（54.0%） | 23.3% | 54.2% |
| **v5** | **485（56.2%）** | 23.8% | 54.5% |
| 参考：当日の人気上位（市場の評価。予想には使えない） | 570（66.0%） | 34.1% | 64.3% |

- 期間別：夏 v5 56.0%・v3 53.4%・全馬共通 45.5%／春 v5 56.6%・v3 55.0%・全馬共通 52.7%。
- v5 − v3 ＝ +2.2pt（95%区間 **+0.3〜+4.2**）。下限が0を上回ったため、**v5 を影の予測に加えた**。
- v5 − 全馬共通 ＝ +8.1pt（+5.6〜+10.8）。ただし主画面の切り替えは前向き評価（final：事前保存100R以上で1回だけ）で判断する。
- 首位の勝率は全馬共通と変わらない（約24%）。改善は「上位3頭に勝ち馬を入れる」方に出ている。
- 当日の人気上位とはまだ約10pt の差がある（調教・当日の状態・陣営の情報などはラボのデータにない）。
