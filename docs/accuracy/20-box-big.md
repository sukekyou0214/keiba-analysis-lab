# 20. 多頭数の注目レース（box-big）

事前登録：`00-plan-and-preregistration.md` の「2026-11-27 多頭数の注目レース box-big」（計算前にコミット 867e110）。計算：`scripts/box_big_test.py`。記録：`20-box-big/run_log_select.json`・`run_log_final.json`。
確認の期間（2025年夏）は 2026-11-27 に1回だけ見た。

## 結論
- **採用しない。** 多頭数（13頭以上）の中で「v5 の上位5頭が1〜3着を占めやすい順」に各日2Rを選んでも、多頭数の全レースより当たりやすいとは確かめられなかった（差 +7.0pt、95%区間 −1.0〜+15.7pt）。
- **妙味も確かめられなかった。** 選んだレースの三連複5頭ボックスの回収率は 75%（95%区間 40〜116%）。多頭数の全レース（57%）より高いが、100%を超えるとは言えない。
- ページには出さない。今の当たりやすさ区分（box-v1、頭数の少ない順）は変えない。

## 結果
| 期間 | 対象 | レース | v5 上位5頭の三連複ボックス的中 | 回収率 | 参考：人気上位5頭の的中 |
|---|---|---|---|---|---|
| 2025年春（選択） | 多頭数の全レース | 201 | 16.9% | 39% | 27.9% |
| | G-B2 各日2R | 40 | 25.0% | 23% | 40.0% |
| | G-B3 各日2R | 40 | 20.0% | 43% | 22.5% |
| 2025年夏（確認・1回） | 多頭数の全レース | 274 | 21.5% | 57% | 27.0% |
| | G-B2 各日2R | 56 | 28.6% | 75% | 35.7% |

- 選択は的中率の高い G-B2（25.0% 対 20.0%）。
- 多頭数では、v5 の上位5頭より人気の上位5頭のほうが当たっている（春・夏とも）。13 の結果と同じ。
- 計算の途中で、回収率の計算が10倍になっている誤りを見つけて直した（選択の期間の1回目の実行。選択は的中率で決まるので、選んだ候補は同じ）。確認の期間は直したあとに1回だけ計算した。
- 限界：過去データでは、出走頭数を実際に走った頭数で代用した。回収率はすべてのレースを同じ金額で買った場合の実際の払戻。

## このあと
- 多頭数の「当たりやすくて配当もよい」レースを、今のラボの点で選ぶことはできていない。18（人気との関係）と合わせると、人気にない情報（調教・血統など）が必要と考えられる。
- 前向きの記録として、多頭数の G-B2 各日2R は計算だけ続けてもよい（表示はしない）。
