# 13. 三連単5頭ボックスで「2.3回に1回（約43%）」は現実的か（調査、2026-11-23）

- 三連単5頭ボックス（60点・6,000円）は、5頭が1〜3着を独占すれば当たる。的中率は三連複5頭ボックスと同じ。
- データ：2026年夏・春のJRA芝、新馬戦を除く 767レース（48日）。v5 は 2025年秋だけで学習（評価期間は未使用）。
- 払戻は手元にないため、単勝オッズからハービル式で三連単確率を出し、払戻率 72.5% で「推定払戻」とした（目安のみ）。
- 抜き出し条件は結果を見てから比べたもの。採用する前に、事前登録をしてレース前の記録で確かめる必要がある。

| 対象 | レース数 | v5的中 | 人気上位5的中 |
|---|---|---|---|
| 全レース | 767 | 28.3% | 38.7% |
| データ充足度 各日上位3R（本番の記録、11/21〜23） | 9 | 1/9 | — |
| 各日 頭数が少ない3R | 144 | 50.7% | 56.9% |
| 各日「v5の5頭の市場確率」上位3R | 144 | 56.9%（夏59.5／春53.3） | 62.5% |
| 頭数5〜8 | 65 | 61.5% | 58.5% |
| 頭数15〜18 | 363 | 17.4% | 31.1% |

- 結論：43% は「レースの選び方」を変えれば届く水準。データ充足度（戦績の揃い具合）で選んだレースは、多頭数の特別戦になりやすく、的中は伸びない。
- 収支：当たったときの推定払戻の中央値は 2,400〜3,900円で、6,000円の購入額を下回る。推定回収率は夏123%・春50%と安定しない。的中率が上がっても、利益が出るとは言えない。
