# 展開予測 v2（pace-v2）の選択と検証

作成：2026-11-16。手順は `00-plan-and-preregistration.md` の 2026-11-16 追記「展開 v2」（計算前に固定）のとおり。

## 方法
- 対象：新馬戦以外で公表S/M/Hが取れたレース。2025年秋 304R・2026年秋 222R（学習）、2026年夏 460R（検証、ペースの判定は未使用）。
- 選択（2025年秋で学習 → 2026年秋の一致率）：P1（しきい値の選び直し）55.4%、**P2（多項ロジット）59.0%** → P2。
- P2 の材料：先行圧力・前に行く傾向の頭数・位置の根拠がある頭数の割合・出走頭数・距離。2025年秋＋2026年秋で学習し直し、2026年夏で1回だけ評価。
- 再現：`python scripts/pace_v2.py --autumn2025 <> --autumn2026 <> --summer2026 <> --out <> --save models/pace_v2.json`

## 結果（2026年夏 460R）

| 判定方法 | 公表S/M/Hとの一致率 |
|---|---|
| **pace-v2（P2）** | **53.5%** |
| 旧版 pace-v1（しきい値 0.5/4.5） | 50.9% |
| 学習期間で最も多い判定（S）を常に答える（事前に決めた比較相手） | 34.8% |
| 参考：後から見て最も多い判定（M）を常に答える | 50.4% |

- v2 − 常にS ＝ +18.7pt（95%区間 +13.7〜+23.5）。事前に決めた条件を満たしたため、**画面の展開予測を v2 に替えた**。
- ただし、夏は公表ペースが M に寄っており（M 232・S 160・H 68）、後から見た「常にM」とは差が小さい（+3.1pt）。
  時期によって S/M/H の比率が変わるので、判定は弱い目安として「暫定」を付けたまま出す。v2 の予測は H が少ない（10/460）。
- 画面：距離が分かるレースでは pace-v2、分からない場合は pace-v1 のしきい値で判定する。位置の根拠が足りないレースは従来どおり保留。
- 本番の関数と検証スクリプトの判定が 460R すべてで一致することを確認した。
