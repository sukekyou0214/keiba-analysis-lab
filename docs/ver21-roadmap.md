# 競馬分析ラボ Ver.21 開発計画

目標: 2026-11-13（金）までにエリザベス女王杯向け安定運用版を検証する。

## 優先する作業
1. 現行機能の回帰テスト（出馬表、総合診断、ペース切替、馬名表示）
2. レース固有コードを汎用レース比較へ切り出す
3. 過去レース相性（出走歴・3着以内歴・人気帯での対照比較）
4. CSV保存（元データ・検証結果・欠損情報）
5. iPhone画面とStreamlit Cloudでの実動作確認

## 安全ルール
- mainは直接変更しない。レビュー後にPRで統合する。
- 実測と推測は区別し、欠損値を捏造しない。
- 予想時点より未来の情報を特徴量に含めない。
- 小標本の相性を断定しない。
- Python構文チェックと集計テストが通るまで統合しない。
- netkeiba等のサイトへのアクセスは利用規約、レート制限を守る。
